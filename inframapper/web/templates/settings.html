How keys are handled

  • Stored server-side in .env (owner-only permissions on Linux / macOS), never in the browser.
  • Tests run on the server; results keep only a short hash of the key, so a replaced key shows as untested.
  • Error messages are built from status codes and are scrubbed of every configured key.
  • “Test” before saving tries an unsaved key without storing it.
